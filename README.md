# Python Task Manager
A command- line task management application written in Python.

## Overview
The program allows users to create tasks, assign priorities, mark tasks as completed and view basic task statistics. Task data is saved to a text file so that tasks remain available when the program is restarted.

## Features
- Add new tasks
- Assign task priorities
- Display all tasks
- Mark tasks as completed
- Track pending and completed tasks
- Save tasks to a file
- Load saved tasks when the program starts
- Display task statistics

## Technologies & Concepts
- Python
- NumPy
- Functions
- Lists and tuples
- Dictionaries
- File handling
- Persistent data storage
- Input handling
- Modular programming

## Project Structure
- `task_manager.py` — main application logic and user interface
- `database.py` — saving and loading task data
- `tasks.txt` — persistent task storage
